# DMIT 洛杉矶评测：Pro、EB、T1 三条线路怎么选，延迟数据、超量限速和全套餐价格说清楚

搜这个关键词的人，通常已经听过 DMIT 在圈里的名声，卡住的地方其实是更具体的几个问题：三条线路到底差多少、$12.98 的入门款够不够用、晚高峰会不会掉速、以及看到一堆 $6.9、$10.9、$12.98 的报价时该信哪个。

这篇按顺序把这些拆开。先说结论：DMIT 洛杉矶最大的分歧从来不是配置高低，而是线路。

## 三条产品线，差在线路不在配置

DMIT（DMIT Cloud Services，自有 ASN AS906）在洛杉矶机房同时卖三个系列，命名很直白：

- **LAX.Pro（Premium）**：IPv4 三网双程 CN2 GIA（AS4809）；IPv6 走 CMIN2 和 9929 动态负载。电信去程 GIA，联通去程直连 AS4837，移动去程经香港移动 AS58453，三网回程统一走 GIA。
- **LAX.EB（Eyeball）**：IPv4 和 IPv6 双栈，三网回程走 AS9929 与 CMIN2 组合。电信去程还是 CN2 GIA，回程换成 9929。
- **LAX.T1（Tier 1）**：纯国际线路，官方说明是对亚美、美洲内部延迟做了优化，**不对中国大陆做优化**。走的是 Telia、Zayo、Cogent 一类国际骨干。

一个常见的误解是把 EB 当成"缩水版 Pro"。实际上 EB 只是把国内回程从 CN2 GIA 换成了 9929+CMIN2。对联通和移动用户来说，这两个组合的差距远比价格差距小；只有电信用户能明显感觉到 Pro 更稳。同理，如果你压根不做国内访问，花钱买 Pro 就是纯浪费。

三个系列都标配 1 个 IPv4 加 1 个 IPv6 /64，KVM 虚拟化，磁盘 I/O 在第三方测评里普遍能跑到 1.0–1.1GB/s，4GB 内存以上支持装 Windows。

## 实测数据：延迟、CPU 和流媒体

第三方测评给出的数据大致是这样一个区间：

AN5 平台（EPYC 9005）的 CPU 提升是这次换代里最实在的部分，有测评测到单核 Geekbench 6 跑分 2650 以上，这个水平拿来建站、跑中等规模应用都够用。

> 上面这些数字来自公开测评，测试节点、测试时间和抽到的 IP 段都会影响结果。同一个套餐，不同用户测出来的流媒体解锁情况可能完全不一样，别把测评数据当成买回来必然复现的结果。

## AN5、AS3、AN4：买之前要搞清楚的代际

这是价格看起来一片混乱的根本原因。近一年多，DMIT 洛杉矶的平台换了好几轮：

- **AN5**：AMD EPYC 9005，最新一代，性能最强，价格也最高。
- **AS3**：AMD EPYC 7003，价格明显更低，洛杉矶 Pro 入门款月付 $10.90 起，T1 年付 $36.9 起。
- **AN4**：AMD EPYC 9004，作为过渡平台上过一段时间，目前官网已基本看不到。

中间的反复也值得知道：AN5 曾经因为硬件成本和 IP 资源问题暂停销售，AN4 临时顶上，之后 AS3 补货，AN5 又返场。所以你会在不同文章里看到同一系列相差三成的报价，绝大多数时候不是谁写错了，而是看的不是一个平台。

## 超量限速、换 IP 和流量重置

这三条政策比参数更影响长期体验。

**超量不停机。** 流量跑完后不直接断网，而是把端口降速继续用。Pro 和 EB 的低配档降到 4Mbps，中高配 8–10Mbps；T1 更宽松，能保留 100–500Mbps。对个人用户来说，4Mbps 还能勉强跑日常，用来应急比直接停机舒服得多。

**换 IP。** LAX Pro 和 LAX EB 上线了换 IP 机制。公开资料里提到的是每 15 天可以免费更换一次，超出频率按次收费（约 $5）。被墙或者 IP 质量变差时有用。具体频率和收费标准以官网当期政策为准，这个规则 DMIT 调整过不止一次。

**流量重置。** 官方上线了流量重置功能，覆盖常规系列产品，不含 WEE 和其余特价机型。流量用光又不想等到下个计费周期，可以手动重置。

## 到底该买哪一个

不用纠结太久，按这三条判断就行：

1. **主力用户是电信、要建站或做回国中转**：Pro。TINY 或 Pocket 起步，$12.98–$18.90 这个区间能试出线路到底合不合你的网络。
2. **联通或移动用户、预算敏感**：EB。同价位流量更多，回程 9929+CMIN2 对这两个运营商的表现和 Pro 的差距没有价格差距那么大。
3. **访问对象在海外，或者只是拿来做国际中转、备份、下载站**：T1。别给它加国内优化的期待，$14.90 的 V2C2G 给的 5TB 流量才它的价值所在。

高配档要不要上？以 Pro 为例，从 STARTER（$38.90）跳到 MINI（$76.90），多出来的是 2GB 内存和 2TB 流量，CPU 核心数反而没变。如果你的瓶颈是内存而不是带宽，这笔差价还可以；如果你只是流量偶尔超一点，先看看 4Mbps 的降速档能不能接受，往往比升级套餐划算。

## 常见问题

**DMIT 洛杉矶会超售吗？** DMIT 的定价明显高于同配置的廉价商家，长期以来的说法是它不在超售上压成本。这个判断没有公开的量化证据，只能从"超量限速而非停售流量"和 CPU 不做激进限制这两点侧面看。

**$12.98 的 TINY 够用吗？** 1核 2G 跑一个 WordPress 站、轻量 API 或代理中转没问题。要同时跑数据库加缓存、或者并发稍高，2GB 内存会先顶不住，跟带宽无关。

**年付划算吗？** 划算。以 AN5.Pro.TINY 为例，月付 $12.98，年付约 $119.99。缺点是一旦平台换代或你想换配置，改计费周期可能触发重新按新价计算，续费价就不一定还在原位。

**那些 $39.9、$49.9 一年的特价机值得抢吗？** 特价机通常是限量款（比如 EB 系列的 CORONA、Pro 系列的 MALIBU），年付四五十美元，配置多为 1核 1G 或 1核 2G，带 2Gbps 左右的端口和 1–2TB 流量。它们不稳，售完即止，也不参与流量重置。想当主力机就别赌库存，当备用机或测试机则很合适。

**支持哪些付款方式？** 支付宝、PayPal 和信用卡，官网有中文界面和中文客服，这对国内用户是实打实的便利。
